# Breathe ESG

Live app: https://breathe-esg-6ukr.onrender.com

Breathe ESG is a Django REST and React prototype for uploading SAP, utility electricity, and corporate travel CSVs, normalizing the data into emissions records, and letting analysts review, approve, or reject rows before audit.

## Stack

- Django
- Django REST Framework
- React
- Vite
- PostgreSQL
- Render
- Gunicorn
- WhiteNoise
